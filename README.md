# 🛒 Flipkart Clone  

![Flipkart Clone Banner](https://raw.githubusercontent.com/ronik-bajakke/FlipkartClone/main/banner.png)

A visually appealing **Flipkart homepage clone** built using **HTML and CSS**.  
This project closely replicates the design and layout of the Flipkart India website — showcasing front-end skills using only static web technologies.

---

## 🌐 Live Demo  

👉 **[Visit the Live Site]( https://soham-patil18.github.io/FlipkartClone/)**  

---

## 🎯 Project Overview  

The **Flipkart Clone** project was created as a front-end development practice exercise.  
It demonstrates proficiency in **HTML structure**, **CSS Flexbox layouts**, and **UI styling** to recreate a professional e-commerce homepage design.


---

## 🧠 Features  

- ✅ Clean and realistic Flipkart homepage replica  
- 🧩 Navigation bar with logo, search bar, login, and cart  
- 🛍️ Category panel with icons and hover effects  
- 🖼️ Hero section featuring a large promotional banner  
- 📦 Product showcase boxes with pricing and captions  
- 🧾 Simple terms/footer section   

---

## 🏗️ Built With  

- **HTML5** — for structuring the webpage  
- **CSS3** — for styling and layout
- **Font Awesome** — for icons (cart, user, search, etc.)

## 🚀 How to Run Locally  

1. Clone the repository  
   ```bash
   git clone https://github.com/Soham-patil18/FlipkartClone.git
   ```  
2. Open the project folder  
   ```bash
   cd FlipkartClone
   ```  
3. Open `index.html` in any web browser
